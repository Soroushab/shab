# RAship Project
This project contains reusable Python functions and automated tests developed as part of a research assistantship.
## Project Structure
- `models/`: Contains reusable Python functions and computational models.
- `tests/`: Contains automated tests to verify that the Python functions work correctly.
- `main.py`: The entry point for running the Python application.
## How to Run
Run the main script using `python main.py` after activating the project environment.
Run the automated tests using `python -m pytest tests/ -v` after activating the project environment.
